# Портфолио: четыре лендинга

Статические сайты на чистом HTML, CSS и JavaScript, без сборки и зависимостей.

| Папка | Проект | Ниша |
|---|---|---|
| `autoservice/` | Торк | Автосервис: калькулятор ТО, отчёт диагностики, запись |
| `beauty/` | Шалфей | Салон красоты: прайс по длине волос, запись по слотам |
| `construction/` | Каркас | Строительство: калькулятор дома, чертёж фасада, график стройки |
| `dental/` | Эмаль | Стоматология: интерактивная зубная формула, рассрочка |

`index.html` в корне — страница-витрина со ссылками на все проекты.

## Локальный запуск

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000.

Все компании, адреса, телефоны и отзывы вымышлены.
